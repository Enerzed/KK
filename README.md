    One‑dimensional array elements

Special Notes

    The main program entry point is the main function (written in C++).

    Functions without parameters may be declared as void.

⚙️ Output File

After successful compilation, the program generates an x64 assembly file output.asm.

This low‑level file can be assembled into an executable using any suitable assembler (e.g., MASM).

Example of generated code:
```assembly
; Assembly generated by compiler (x64)
option casemap:none
includelib kernel32.lib
extern ExitProcess : proc
_BSS SEGMENT PUBLIC
g@01 DD 1H DUP (?)
_BSS ENDS
_TEXT SEGMENT
main@02 PROC
    push rbp
    mov rbp, rsp
    sub rsp, 48
    ; ... further generated code
main@02 ENDP
_start PROC
    sub rsp, 28h
    call main@02
    mov ecx, eax
    call ExitProcess
_start ENDP
_TEXT ENDS
END _start
```
